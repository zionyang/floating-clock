# 悬浮时钟

面向限时抢购任务的轻量 Windows 悬浮时钟，采用 Tauri + WebView2。

## 功能

- 无边框、始终置顶的悬浮时钟，可从标题栏拖动。
- 固定大小窗口，支持任务栏入口和托盘召回。
- 单实例启动：再次启动时显示已有窗口，不重复创建。
- 使用全局 `Ctrl+Alt+T` 快捷键和托盘菜单快速显示或隐藏窗口。
- 保存窗口位置，并记住上次选择的显示模式和时间源。
- 托盘菜单支持开机启动和鼠标穿透。
- 标题栏菱形按钮控制窗口是否保持在其他窗口上方。
- 支持实时时钟和北京时间倒计时两种模式。
- 标准模式下点击主时间数字，可在三位小数秒与整数秒显示间切换；Mini 延用当前显示精度。
- 支持 Mini 模式：仅显示当前时钟或倒计时数值，宽度会随超长倒计时自动调整。
- 倒计时支持下一整点、下一个 `10:00` 和下一个 `20:00` 快捷目标。
- 整点或倒计时目标前最后五秒高亮显示。
- 支持切换北京时间、京东、拼多多、淘宝、美团、美团闪购、淘宝闪购和大麦时间源。
- 时间校准通过 Tauri 的 Rust 原生网络请求执行，不受网页跨域限制。
- 直接毫秒接口和 NTP 每次最多采样三次，选择 RTT 最短的样本。
- 全部时间源都优先使用可公开验证的平台毫秒接口，校准达标时默认显示毫秒。毫秒策略失败会自动回退到 HTTP `Date` 秒边界校准，此时默认显示整秒，也可点击切换为基于已校准偏移推算的毫秒；底部会以红字说明原因。

## 时间源

| 时间源 | 校准方式 | 显示与失败处理 |
| --- | --- | --- |
| 北京时间 | 首选 `ntp.ntsc.ac.cn:123`，依次回退腾讯、阿里云和 Cloudflare 的 NTP 时间戳 | 取得有效 NTP 响应后即可显示毫秒；失败时保留当前来源的上次偏移或暂用本机时间 |
| 京东时间 | 首选 `api.m.jd.com` 响应头 `X-API-Request-Id` 的毫秒段（与 `Date` 头交叉校验）；失败回退同域 HTTP `Date` 秒边界 | 毫秒策略成功即显示毫秒；回退后默认整秒并红字标明；全部失败时保留京东的上次偏移或暂用本机时间 |
| 拼多多时间 | JSON `server_time`，再到 `yak-timeinfo` | 直接毫秒字段成功时可显示毫秒；字段不可用或校准质量不足时默认整秒，可切到偏移推算的毫秒 |
| 淘宝时间 | MTop `data.t` 直接毫秒时间 | 直接字段成功时可显示毫秒；字段不可用或校准质量不足时默认整秒，可切到偏移推算的毫秒 |
| 美团时间 | 首选 `cube.meituan.com` 服务器时间接口的毫秒字段；失败回退 `www.meituan.com` 的 HTTP `Date` 秒边界 | 毫秒策略成功即显示毫秒；回退后默认整秒并红字标明；全部失败时保留美团的上次偏移或暂用本机时间 |
| 美团闪购时间 | 首选与美团相同的 `cube.meituan.com` 毫秒接口（共用美团时基，独立采样）；失败回退 `brandhub.meituan.com` 的 HTTP `Date` 秒边界 | 毫秒策略成功即显示毫秒；回退后默认整秒并红字标明；全部失败时保留美团闪购的上次偏移或暂用本机时间 |
| 淘宝闪购时间 | 首选饿了么 MTop 网关 `waimai-guide.ele.me` 的 `mtop.common.getTimestamp` 毫秒字段；失败回退 `www.ele.me` 的 HTTP `Date` 秒边界 | 毫秒策略成功即显示毫秒；回退后默认整秒并红字标明；全部失败时保留淘宝闪购的上次偏移或暂用本机时间 |
| 大麦时间 | 首选大麦 MTop 网关 `mtop.damai.cn` 的 `mtop.common.getTimestamp` 毫秒字段；失败回退 `www.damai.cn` 的 HTTP `Date` 秒边界 | 毫秒策略成功即显示毫秒；回退后默认整秒并红字标明；全部失败时保留大麦的上次偏移或暂用本机时间 |

相位校准是毫秒接口失败后的自动回退：以独立缓存破坏参数和 `no-cache` 请求连续采样，捕捉相邻的 HTTP `Date` 秒边界。HTTP `Date` 本身只有秒粒度，因此回退状态默认显示整秒；用户可切到由已校准偏移和本机时钟推算的毫秒，界面同时标明“非平台级严格毫秒”，且保留实际的 `误差 ±N ms` 供校准状态查看。它不冒充平台业务服务器公开的毫秒字段。淘宝与淘宝闪购、美团与美团闪购始终独立采样，不共享校准偏移；其中美团与美团闪购的毫秒策略访问同一个美团接口，时钟基准相同，回退的 `Date` 校准仍使用各自域名。

倒计时始终使用当前选中的时间源：切换到倒计时不会自动改为北京时间。应用启动时会校准一次，之后每 10 分钟自动校准；也可手动立即重试。所有策略都失败时，如果当前时间源已有成功校准的偏移，则保留该偏移；否则暂时使用本机时间。界面会显示实际策略、RTT 或校准窗、估计误差和偏移。

最小化窗口或按 `Esc` 时，窗口会隐藏到托盘；关闭按钮、`Alt+F4` 或托盘菜单中的退出选项会退出程序。需要重新显示时，可以使用 `Ctrl+Alt+T`、托盘图标或托盘菜单。若 `Ctrl+Alt+T` 已被其他程序占用，应用仍会正常启动，托盘会标示快捷键不可用，此时可通过托盘图标或菜单操作。

开机启动和鼠标穿透通过托盘菜单控制。开启鼠标穿透后，悬浮层会忽略鼠标输入，关闭托盘菜单中的对应选项后恢复。标题栏菱形按钮控制悬浮层是否保持在其他窗口上方。

Mini 模式从标题栏左侧的收起图标、标题栏可拖动空白区的双击或托盘菜单进入，显示当前时间源、时钟或倒计时数值和日期。它在本次运行内固定置顶，托盘中的“窗口置顶”会被锁定；切回标准模式后恢复进入 Mini 前的置顶设置。鼠标悬停 Mini 窗口时，最右侧会依次显示关闭（退出应用）、最大化（恢复标准模式）和最小化（隐藏到托盘）三个图标；双击时间区域也可直接恢复标准模式。除这三个按钮及其周边留白外均可直接拖动窗口。Mini 状态不会跨重启保存，应用下次启动仍为标准模式。

Mini 的置顶仅作用于当前 Windows 虚拟桌面，不会自动显示在所有虚拟桌面。需要跨桌面可见时，请在 Windows 任务视图中对该窗口或应用使用“在所有桌面上显示”。

## 隐私、第三方服务与使用限制

- 本项目不设自有后端；代码不包含向开发者收集、上传或共享个人数据的功能。窗口位置、显示模式和时间源等偏好仅保存在本机。
- 校时会向以下第三方发起网络请求：NTP 服务 `ntp.ntsc.ac.cn`、`ntp.tencent.com`、`ntp.aliyun.com`、`time.cloudflare.com`；HTTP 服务 `api.m.jd.com`、`api.pinduoduo.com`、`www.pinduoduo.com`、`h5api.m.taobao.com`、`www.taobao.com`、`cube.meituan.com`、`www.meituan.com`、`brandhub.meituan.com`、`waimai-guide.ele.me`、`www.ele.me`、`mtop.damai.cn` 和 `www.damai.cn`。与任何普通网络请求一样，这些服务可接收请求来源 IP 地址和 `User-Agent`。
- 本项目是独立开源项目，不代表、未获上述服务商授权，也不保证与其服务持续兼容。
- 第三方端点可能变更、限流、拒绝访问或返回不适合校时的数据；应用会按现有策略降级或回退，但不保证校时可用性、精度或抢购结果。

```powershell
npm install
npm run dev
```

```powershell

```

## Windows 构建

唯一的正式打包入口、版本规则、产物目录和验收步骤见 [打包流程](docs/打包流程.md)。Tauri 构建需要 Rust、Microsoft C++ Build Tools 和 WebView2：

```powershell
npm run tauri:build
```

正式分发文件会写入 `dist/`；`src-tauri/target/release` 及其 `bundle/` 子目录是 Tauri 的内部构建产物。NSIS 安装程序使用 Tauri 的 `downloadBootstrapper` 模式：目标电脑缺少 WebView2 时，安装过程需要联网下载运行时。
