# 悬浮时钟

面向限时抢购任务的轻量 Windows 悬浮时钟，采用 Tauri + WebView2。

## 功能

- 无边框、始终置顶的悬浮时钟，可从标题栏拖动。
- 固定大小窗口，支持任务栏入口和托盘召回。
- 单实例启动：再次启动时显示已有窗口，不重复创建。
- 使用全局 `Ctrl+Alt+T` 快捷键和托盘菜单快速显示或隐藏窗口。
- 保存窗口位置，并记住上次选择的显示模式和时间源。
- 托盘菜单支持开机启动和鼠标穿透。
- 标题栏菱形按钮控制窗口是否保持在其他窗口上方。
- 支持实时时钟和北京时间倒计时两种模式。
- 倒计时支持下一整点、下一个 `10:00` 和下一个 `20:00` 快捷目标。
- 整点或倒计时目标前最后五秒高亮显示。
- 支持切换北京时间、京东、拼多多、淘宝、美团、美团闪购和淘宝闪购时间源。
- 时间校准通过 Tauri 的 Rust 原生网络请求执行，不受网页跨域限制。
- 直接毫秒接口和 NTP 每次最多采样三次，选择 RTT 最短的样本。
- 没有公开毫秒接口的平台使用独立的 HTTP `Date` 秒边界相位校准；校准失败不会回退为秒级时间。

## 时间源

| 时间源 | 毫秒策略 | 失败处理 |
| --- | --- | --- |
| 北京时间 | `ntp.ntsc.ac.cn:123` 的 NTP 时间戳，含小数秒 | NTP 不可用则本次校准失败 |
| 京东时间 | `https://api.m.jd.com/` 的 `Date` 秒边界相位校准 | 校准失败 |
| 拼多多时间 | JSON `server_time`，再到 `yak-timeinfo`；均为直接毫秒时间 | 两者失败后做独立相位校准 |
| 淘宝时间 | MTop `data.t` 直接毫秒时间 | 失败后做独立相位校准 |
| 美团时间 | `https://www.meituan.com/` 的独立相位校准 | 校准失败 |
| 美团闪购时间 | `https://brandhub.meituan.com/` 的独立相位校准 | 校准失败 |
| 淘宝闪购时间 | `https://www.ele.me/` 的独立相位校准 | 校准失败 |

相位校准会以独立缓存破坏参数和 `no-cache` 请求连续采样，捕捉相邻的 HTTP `Date` 秒边界。只有响应未显示缓存、相位窗口不超过 200ms 时才接受，并显示 `误差 ±N ms`；否则本次校准失败。它是平台网关时钟的带误差估计，不冒充平台业务服务器公开的毫秒字段。淘宝与淘宝闪购、美团与美团闪购始终独立采样，不共享校准偏移。

所有策略都失败时，如果当前时间源已有成功校准的偏移，则保留该偏移；否则暂时使用本机时间。界面会显示实际策略、RTT 或校准窗、估计误差和偏移。

最小化窗口或按 `Esc` 时，窗口会隐藏到托盘；关闭按钮、`Alt+F4` 或托盘菜单中的退出选项会退出程序。需要重新显示时，可以使用 `Ctrl+Alt+T`、托盘图标或托盘菜单。若 `Ctrl+Alt+T` 已被其他程序占用，应用仍会正常启动，托盘会标示快捷键不可用，此时可通过托盘图标或菜单操作。

开机启动和鼠标穿透通过托盘菜单控制。开启鼠标穿透后，悬浮层会忽略鼠标输入，关闭托盘菜单中的对应选项后恢复。标题栏菱形按钮控制悬浮层是否保持在其他窗口上方。

## 运行

```powershell
npm install
npm run dev
```

## 测试

```powershell
npm test
```

## Windows 构建

Tauri 构建复用现有渲染器，需要 Rust、Microsoft C++ Build Tools 和 WebView2：

```powershell
npm run tauri:build
```

原始可执行文件和 NSIS 安装程序会写入 `src-tauri/target/release`。NSIS 安装程序使用 Tauri 的 `downloadBootstrapper` 模式：目标电脑缺少 WebView2 时，安装过程需要联网下载运行时。
